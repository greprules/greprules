# Code of Conduct

greprules is an open-source project for safer SAST rule discovery and local
agent scans. We want contributors, users, and maintainers to be able to discuss
security tooling with clear technical feedback and professional respect.

## Expected behavior

- Be respectful and constructive, especially when discussing security findings,
  false positives, rule quality, or scanner behavior.
- Keep feedback specific and actionable. Include reproduction steps, affected
  files, commands, logs, or rule IDs when possible.
- Assume good faith, but be willing to correct mistakes with evidence.
- Respect privacy and confidentiality. Do not publish secrets, private source
  code, exploit details, or sensitive vulnerability information in public
  issues or pull requests.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing private credentials, tokens, customer data, or non-public
  vulnerability details.
- Repeatedly derailing technical discussions after maintainers have asked to
  refocus.
- Spam, abusive automation, or attempts to disrupt project infrastructure.

## Reporting

For conduct concerns, contact the maintainers through GitHub. For security
vulnerabilities, follow the private reporting process in [SECURITY.md](SECURITY.md).

Maintainers may remove content, close issues or pull requests, block users, or
take other moderation actions when needed to protect the project and community.
